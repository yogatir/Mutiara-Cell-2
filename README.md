# Mutiara Cell 📱

Website resmi **Mutiara Cell** - Pusat retail dan grosir smartphone, tablet, smartwatch, dan aksesoris original terlengkap dengan garansi resmi.

## ✨ Fitur Utama
- **Katalog Produk Lengkap**: Smartphone (Apple, Samsung, Xiaomi, Vivo, Oppo, Infinix) & Aksesoris Original.
- **Filter & Kategori Realtime**: Filter berdasarkan brand, kategori produk, dan pencarian cepat.
- **Keranjang Belanja (Cart Drawer)**: Pengelolaan pesanan interaktif.
- **Checkout WhatsApp Otomatis**: Integrasi pesanan langsung ke Customer Service via WhatsApp dengan format rapi.
- **Detail Modal Produk**: Tampilan spesifikasi lengkap, varian warna & kapasitas, serta garansi.
- **Desain Responsif**: Dioptimalkan untuk tampilan desktop, tablet, dan smartphone dengan Tailwind CSS.
